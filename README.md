# TalentHub Landing Page

Production React TypeScript implementation of the TalentHub enterprise ATS landing page.

## Commands

```bash
npm install
npm run dev
npx tsc --noEmit
npm run lint
npm run build
```

## Stack

- Vite React TypeScript
- Tailwind CSS v3 with PostCSS and Autoprefixer
- shadcn-style UI primitives
- dnd-kit Kanban drag and drop
- Plus Jakarta Sans via Google Fonts
